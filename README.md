# Creator-Aware AI: online notes

These are the source notes for *Creator-Aware AI: Building AI That Remembers Who Made It and Never Rules Us*, by Anthony Doyle, with the web address for every source. The printed book gives each source by author, title and date. The links live here so that they can be kept up to date.

The notes follow the book: arranged by chapter, and keyed to the page and to the words in the text each one supports. Page numbers refer to the Amazon Paperback Edition (ISBN 9798140164447). Kindle readers can find a note by searching for the words it quotes.

Web addresses were checked in October and November 2026. Pages change and links break. Where an address no longer works, try the Internet Archive's Wayback Machine (web.archive.org) with the same address.
